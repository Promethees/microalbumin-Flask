On device —
Sensor calibration Makes every cuvette holder report the same count from the same LED.
  1. Load every holder the same way. All empty, or the same blank cuvette moved into each slot — whatever is left different between the holders is what gets divided out.
  2. Check the light first. The same LED in every holder, and on the device's Raw Count screen set gain and integration time until no channel reads OVFL.
  3. Press Calibrate now. Takes a few seconds. If a holder is refused by name, that slot is the problem — a dark LED, an empty holder, or a cuvette left behind — fix it and run again.
  4. Copy the array into configuration.json on the CIRCUITPY drive. The device cannot write that file itself, so the factors are lost on the next power cycle until you do.
  5. Run it again after the instrument is moved or re-lamped, or if it has sat unused: LED output falls with age.

This does not change Absorbance or Transmittance — each channel is already divided by its own blank, which cancels the factor. It changes Raw Count, Irradiance, and any comparison between holders. If absorbance still disagrees between holders afterwards, the cause is elsewhere: pathlength, cuvette orientation, scattering, or a blank taken through different contents.
