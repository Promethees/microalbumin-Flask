    Activation, seats and hardware binding

    1. The desktop application is activated with a licence token issued to your account. On activation the application computes a hardware fingerprint of the machine — a SHA-256 digest of a stable operating-system machine identifier — and the token is cryptographically bound to it.
    2. A token is valid on one machine. Copying an activated installation, or the activation.json file inside it, to a second machine will not work: the fingerprint will not match and the application will refuse to start.
    3. The application contacts our server on start-up and periodically thereafter to confirm that its licence is still valid. If the machine is offline, the application continues to run on its last known good state until the next successful check.
    4. If you change or reinstall a machine and need the seat moved, contact us at tqmthong@gmail.com and we will revoke the old seat and issue a replacement.
    5. We may revoke an individual seat, or ban an account entirely, if these terms are breached — see §11. When that happens the desktop application stops working and shows the reason.
